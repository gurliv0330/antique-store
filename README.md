# antique-store
An antique store with historical fiction items


My original idea (which I might play around with later): 
This is basically like a game-ish experience with an antique store with historical fiction items. I'm thinking kind of like the time travel necklace thing from harry potter, some weird book or like a handwritten letter. I'll maybe add some Harry Potter stuff like the invisibility cloak, or the marauderer's map. I'm not sure if that is the name, I just love the map so much I don't know why. I want to add like some simple puzzles to each item so that in the end you can acomplish something, or maybe unlock a phrase or a word. Kind of like let's say item no. 1 gives you the first letter, or the first word of the phrase. For the colors and stuff I want to make like an old antique ish theme, but a little different so it gives off that harry potter vibe. I will be using HTML, CSS JavaScript.
